📊 Nepal Climate-Agriculture Analysis

This project integrates climate, glacial, and agriculture data for Nepal, applies feature engineering, and performs clustering to discover patterns.

🔍 Project Workflow

📁 Data Merging
  • Combines district-level precipitation
  • Joins basin-level glacial data
  • Includes national-level agriculture indicators
🛠 Feature Engineering
  • Handles missing values
  • Creates interaction & normalized features
  • Encodes categorical variables
🧠 Clustering
  • Applies KMeans clustering on cleaned data
  • Determines optimal cluster count via Elbow method
📊 Visualization
  • Interactive plots via Streamlit dashboard
  • Correlation heatmap and scatter plots
